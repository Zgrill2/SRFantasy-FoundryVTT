# Overview

This project is to create the Shimmering Reach system in FoundryVTT. The Shimmering Reach system is a custom system that is heavily inspired by ShadowRun's d6 dicepool mechanics but takes a fantasy aesthetic Dungeons and Dragons style world.

The SR5-FoundryVTT folder is the Shadow Run 5 system built for FoundryVTT downloaded from GitHub. It is here only as a reference for how to implement in Foundry and should not be modified nor should the mechanics be directly lifted.

The FoundryVTT dev docs can be found here: https://foundryvtt.com/api/
